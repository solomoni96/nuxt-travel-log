# Nuxt Travel Log

A fullstack application built with Nuxt that allows users to keep track of their travel experiences. Users can create, read, update, and delete travel logs, as well as view logs from other users.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```
