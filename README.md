# Nuxt Travel Log

A fullstack application built with Nuxt that allows users to keep track of their travel experiences. Users can create, read, update, and delete travel logs, as well as view logs from other users.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```

### Linting

This project uses ESLint for linting. To run the linter, use the following commands:

```bash
# Run the linter
npm run lint

# Automatically fix linting errors
npm run lint:fix
```

The ESLint configuration for this project uses [@antfu/eslint-config](https://github.com/antfu/eslint-config) with applicable overrides set.
